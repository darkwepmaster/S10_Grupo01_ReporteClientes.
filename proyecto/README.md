# Proyecto Integrador – Reporte de clientes (S10)
1. `python -m venv .venv` y activar el entorno.
2. `pip install -r requirements.txt`
3. Copiar `.env.example` a `.env` y completar las credenciales de SQL Server.
4. `python app.py` y abrir http://127.0.0.1:5000/reportes/clientes
5. Pruebas: `pytest -q`

Esta rama se utiliza para practicar el desarrollo de mejoras en el sistema de reportes de clientes.
